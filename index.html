Robot & field

Use the red/blue button beside the field to choose the robot's alliance color. Click a corner tube to add a match load; right-click it or use EDIT LOAD to change its options.
Place up to four robots, two per alliance. Click a cup, pin, or cup-and-pin assembly to attach it to the nearest robot. Each robot carries one object at a time; a cup with a pin counts as one. Return a robot's object before picking up another.
Draw creates field annotations. Straight path uses two clicks; the active robot's path connects to the first point and then travels straight to the second. Use Select / waypoints to interact with field objects.
Click a wall toggle once to flip it: blue-side toggles cycle yellow → red → blue; red-side toggles cycle yellow → blue → red.
Scoring areas and field elements are approximations based on the supplied images, not official dimensions. A custom 2D image does not change the 3D model.

Save & export

CSV exports the active robot's path (inches; 0° is +X, counterclockwise positive). The initial heading does not constrain the curve. Save project includes all 10 scenes and field images.
Preview only: this is not a drivetrain controller or collision checker. Check robot clearance and test paths safely before use.
